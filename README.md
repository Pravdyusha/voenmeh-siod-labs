**Репозиторий содержит практические работы** по дисциплине  
**«Структуры и организация данных»** (кафедра О7, БГТУ «Военмех» им. Д. Ф. Устинова)

**Язык:** C / C++

## Изученные темы

- Линейные структуры данных (односвязные списки, дек)
- Нелинейные структуры данных (бинарные деревья, графы)
- Представление графов: матрица весов и списки смежности
- Анализ пространственной и временной сложности структур
- Алгоритмы поиска кратчайшего пути (Дейкстра, Флойд-Уоршелл)
- Красно-чёрные деревья и рандомизированные бинарные деревья поиска
- Оценка эффективности алгоритмов поиска

### Практическая работа №2 — Нелинейные структуры данных

**Уровень сложности:** повышенный

**Изученные темы:**
- Восстановление бинарного дерева по прямому и симметричному обходу

- Поиск минимального пути `S + P` (Дейкстра + Флойд-Уоршелл)
